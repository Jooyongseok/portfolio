# Portfolio curation

1. Read public candidates from the approved vault note and repository metadata. Treat all source repositories as private unless the user confirms public display.
2. For every selected project, produce: problem, personal role, AI role, technical decision, verification evidence, and one public-safe outcome. Do not invent metrics or claim model capability without evidence.
3. Keep AI usage specific: distinguish research assistance, implementation assistance, user-facing model behavior, and automated evaluation.
4. Record Antigravity prompt, sources, options rejected, selected output, and selection rationale in a vault research or design note.
5. Before publishing, check for tokens, private URLs, customer data, unapproved screenshots, personal contact details, and misleading claims.
6. Update the portfolio's public content model and HTML resume together. Generate a PDF only from the verified resume HTML.
7. Report candidate projects, excluded private material, changed public claims, and the validation commands run.
